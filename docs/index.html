开始

三步上手

下载、放到应用程序、授权——不用 Xcode。

  1. 01

    下载

    获取 Universal Binary，Apple Silicon 与 Intel 都能用。

  2. 02

    拖到应用程序

    拖进「应用程序」。若提示无法打开，右键图标选择「打开」。

  3. 03

    授权实控

    点击授权并输入密码，助手以 LaunchDaemon 写入 SMC。

长时间手动控温后，请切回「系统自动」。Apple Silicon（M3/M4）可能受 thermalmonitord 约束，MacFan 已内置解锁流程。

开发者可从 GitHub 克隆源码。
