Get Started

三步上手

克隆、运行、授权——不到一分钟体验界面，授权后即可真正调速。

01

克隆

git clone https://github.com/linux503/MacFan.git
cd MacFan && open MacFan.xcodeproj
02

运行

Xcode 选择 My Mac，⌘R。首次可先体验界面与场景逻辑。

03

授权实控

点击「授权管理员权限」，输入密码后即可写入 SMC 真正调速。

长时间手动控温后，请切回「系统自动」。Apple Silicon（M3/M4）可能受 thermalmonitord 约束，MacFan 已内置解锁流程。
